# Аналіз оновлень та релізів Personal Skill Monitor

В результаті аналізу кодової бази та історії змін було виявлено наступні ключові оновлення, які потребують відображення в документації:

## 1. Рефакторинг структури проекту
Значні зміни відбулися в організації файлів проекту. Старий файл `esi_client.py` був видалений, а логіка розділена та переміщена в директорію `src/`.
- **Нова структура:**
  - `src/core/`: Містить основну бізнес-логіку (`controller.py`), клієнт ESI (`esi.py`) та менеджер авторизації (`auth.py`).
  - `src/gui/`: Відповідає за графічний інтерфейс (`app.py`, `components/`).
  - `src/data/`: Містить базу даних навичок (`skills_db.py`, `skill_prerequisites.py`).
  - `src/utils/`: Утиліти (`config.py`, `export.py`, `paths.py`).

## 2. Нові функції та покращення

### Skill Plan Manager (Менеджер планів навичок)
Це значне нововведення, яке дозволяє створювати та керувати власними планами тренувань.
- **Можливості:**
  - Створення, перейменування та видалення планів.
  - Додавання навичок подвійним кліком з автоматичним додаванням пререквізитів.
  - Пошук та фільтрація навичок за групами.
  - Імпорт та експорт планів (Clipboard, TXT).
  - Візуалізація поточного статусу навички в плані (наприклад, "In plan up to level X").

### Відображення атрибутів персонажа
У вікні черги навичок (Skill Queue) додано відображення поточних атрибутів персонажа.
- **Деталі:** Відображаються значення Intelligence, Memory, Perception, Willpower, Charisma (наприклад: `INT:20 MEM:20 PER:20 WIL:20 CHA:19`).

### Інші зміни
- **Themes:** Підтримка теми "EVE Dark" реалізована через `src/ui/theme_eve.py`.
- **Конфігурація:** Завантаження токенів та налаштувань тепер обробляється через `src/utils/config.py`.
